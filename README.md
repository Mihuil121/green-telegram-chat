# Telegram-чат на GREEN-API

Тестовое задание «Фронтенд разработчик React». Веб-чат для отправки и получения **текстовых** сообщений
в Telegram через [GREEN-API](https://green-api.com). Задание допускает Telegram вместо MAX.
Внешний вид — по мотивам Telegram Web.

## Что умеет

- Вход по `idInstance` и `apiTokenInstance` (проверяется `getStateInstance`, инстанс должен быть авторизован).
- Создание чата по номеру телефона (или `@username`): `checkAccount` возвращает `chatId`.
- Отправка текста методом `sendMessage`, повторная отправка при ошибке.
- Получение ответов через HTTP API: `receiveNotification` (long polling, 20 с) → `deleteNotification`.
- Ответ собеседника появляется в чате сам, без перезагрузки страницы.
- Адаптив: на телефоне список чатов и переписка открываются по очереди; светлая и тёмная темы.

## Настройка GREEN-API (один раз)

1. Зарегистрируйтесь в личном кабинете GREEN-API и создайте **Telegram-инстанс** (тариф «Разработчик» бесплатный).
2. Авторизуйте инстанс: отсканируйте QR-код в приложении Telegram.
3. В настройках инстанса:
   - **webhookUrl оставьте пустым** — иначе `receiveNotification` всегда возвращает пустой ответ;
   - включите «Получать уведомления о входящих сообщениях».
4. Скопируйте `idInstance` и `apiTokenInstance`. Изменения настроек могут применяться до 5 минут.

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173), введите `idInstance` и `apiTokenInstance`.
Адрес API подставляется сам по первым четырём цифрам `idInstance`
(например, `4100` → `https://4100.api.green-api.com`). Если в кабинете указан другой — раскройте «Адрес API».

Сборка: `npm run build` → папка `dist/` (статический сайт, подойдёт для GitHub Pages / Netlify / Vercel).

## Как проверить сценарий

1. Войдите с данными инстанса.
2. Введите номер получателя в международном формате (например, `79991234567`) → «Создать чат».
3. Напишите сообщение и отправьте (Enter; Shift+Enter — перенос строки).
4. С аккаунта получателя ответьте в Telegram — ответ появится в чате в течение нескольких секунд.

## Структура

```
src/
  api.js                    клиент GREEN-API (getStateInstance, checkAccount, sendMessage, receive/deleteNotification)
  hooks/useMessenger.js     состояние чатов, отправка, цикл получения уведомлений
  components/Login.jsx      вход
  components/Sidebar.jsx    список чатов и создание нового
  components/ChatView.jsx   переписка и поле ввода
```

## Заметки

- Учётные данные и переписка хранятся только в `sessionStorage` вкладки и очищаются кнопкой «Выйти».
  Запросы идут напрямую в GREEN-API, без своего сервера.
- Сообщения не из текста (фото, файлы и т. п.) и групповые чаты не отображаются — по условию нужен только текст.
- Если номер скрыт настройками приватности Telegram, `checkAccount` может его не найти — используйте `@username`.
